# Changelog

All notable changes to Music Player are documented here.

## [1.0.0] - 2026-11-26

### Added
- Pemutar musik lokal dengan pencarian dan filter folder.
- Pemutaran audio online dari URL HTTPS langsung yang sah.
- Background playback, kontrol media, notifikasi, dan lockscreen.
- Tampilan Now Playing dengan metadata lagu dan artwork.
- Equalizer 12-band dan pengaturan subwoofer/deep bass.
- Spectrum visualizer 28-band dengan pilihan gaya tampilan.
- Lirik manual per lagu dan opsi untuk mengaktifkan atau menonaktifkannya.
- Pilihan tema warna dan gaya visual: Glass, 3D, Neon, Aurora, dan Minimal.
- Pengaturan kualitas unduhan untuk sumber file yang mendukung.
- Pengunduhan offline untuk sumber yang mengizinkan pengunduhan; bukan untuk mengekstrak audio YouTube.
- Pemutar YouTube melalui pemutar/embed resmi, tanpa ekstraksi atau pengunduhan.
- Pengaturan bahasa: Indonesia, English, Español, Français, Deutsch, dan Português; mode otomatis mengikuti bahasa perangkat.
- Halaman pengaturan, informasi proyek, dan navigasi kembali.
- Pemeriksaan pembaruan melalui GitHub Releases serta pengunduhan APK dari aplikasi.

### Changed
- Penyempurnaan tampilan glassmorphism, kedalaman permukaan, dan kontrol equalizer.
- Penyempurnaan navigasi dan pemulihan posisi/riwayat halaman.

### Notes
- Ini adalah catatan fitur untuk target rilis 1.0.0.
- Rilis APK bertanda tangan belum diterbitkan. Pembaruan dalam aplikasi baru dapat digunakan setelah GitHub Release berisi APK resmi tersedia.
- Instalasi pembaruan Android memerlukan konfirmasi pengguna. APK pembaruan harus ditandatangani dengan kunci yang sama seperti aplikasi yang terpasang.
- Sumber audio harus digunakan sesuai izin dan ketentuan layanan masing-masing.
